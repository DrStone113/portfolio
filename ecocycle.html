Architecture

One shared fleet domain,
three focused layers.

01

Dispatcher UI

React + Vite and OpenLayers provide a web workspace for fleet status, map context, route history and reports.

React · OpenLayers · Socket.IO client
02

Operational API

NestJS separates auth, fleet, telemetry, routing and reporting into maintainable modules with shared DTOs.

NestJS · TypeScript · JWT · Argon2
03

Data & Routing

Timeseries telemetry, caching and road-aware matching support high-frequency vehicle updates and route analysis.

PostgreSQL · TimescaleDB · Redis · GraphHopper
